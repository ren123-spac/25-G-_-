# DDS task 2 and task 4 test notes

## Hardware path

```text
STM32H743 -- software SPI --> AD9959 CH0 --> 7x amplifier/follower --> known model RF2
known model RF1 --> oscilloscope
```

## Power-up behavior

The DDS starts with amplitude command 0. Select a task from USART1 before connecting
the signal path for a measurement.

- UART: USART1, 115200 baud, 8 data bits, no parity, 1 stop bit
- Output channel: AD9959 CH0
- Ground: keep the H743, amplifier, DDS and known-model signal grounds common

## Task 2

Task 2 is for the 100 Hz to 1 MHz frequency range, with a 100 Hz step. The maximum
amplitude command is 440. Your measurement was about 3.06 Vpp from 1 kHz to 1 MHz.
Disconnect the known model before selecting this maximum-amplitude mode.

```text
2<Enter>              enter task 2 at the current frequency
1000<Enter>           set 1 kHz
1234<Enter>           round to 1.2 kHz
1000000<Enter>        set 1 MHz
+                     increase by 100 Hz
-                     decrease by 100 Hz
m                     restore amplitude command 440
?                     print help
```

## Task 4

Task 4 uses the model transfer function

```text
H(s) = 5 / (1e-8*s^2 + 3e-4*s + 1)
```

The command line is the only automatic model-output command:

```text
4 frequency target_voltage<Enter>
```

The reference calibration can be changed before the output command. The value is
in millivolts and is kept in RAM until reset:

```text
4 X 2010<Enter>       set reference output to 2010 mV
4 X 2030<Enter>       restore the current default reference
```

Frequency is clamped and rounded to 100 Hz..3000 Hz in 100 Hz steps. The target
voltage is clamped to 1.0..2.0 Vpp in 0.1 V steps. The firmware calculates the
AD9959 amplitude command from the model magnitude and the current calibrated
reference value. The firmware prints the selected reference and amplitude command.

```text
4 1000 2.0<Enter>     1 kHz, target 2.0 Vpp
4 3000 1.3<Enter>     3 kHz, target 1.3 Vpp
4 0300 1.9<Enter>     300 Hz, target 1.9 Vpp
```

The old standalone `3<Enter>` command is disabled.

After sending a complete Task 4 line, frequency and amplitude are written
automatically. Do not adjust the signal generator or the board during the result
measurement.

## Task 5: unknown-model learning prototype

This development version uses USART1 command `5` to start learning. The physical
learning-key GPIO is not assigned yet.

Learning connection:

```text
AD9959 CH1 -> unknown-model input
PC5/ADC1  -> actual input voltage Vin
PA3/ADC1  -> unknown-model output voltage Vout
unknown-model ground, ADC ground and AD9959 ground -> common ground
```

PC5 and PA3 must receive signals conditioned to the 0..3.3 V ADC range. Use an
isolated AC-coupling and 1.65 V bias circuit; do not connect 1.65 V directly to
the RLC model node. The DMA buffer stores interleaved pairs: PC5 first, PA3 second.

```text
5<Enter>              start CH1 sweep and unknown-model learning
```

The prototype sweeps 100 Hz..100 kHz, prints Vin, Vout and gain at each coarse
frequency, classifies low pass, high pass, band pass or band stop, and refines a
band-pass peak and its two -3 dB frequencies. For the test model
R=1489 ohm, L=8.2 mH and C=9.6 nF, expect a band-pass peak near 17.94 kHz.
CH1 is connected directly to the RLC model in this prototype; amplitude command
521 is approximately 500 mVpp based on the previous direct-output measurement.
