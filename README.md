# 2025年电赛G题——未知电路扫频测量与响应复现装置

未知电路扫频测量装置 
•项目介绍：搭建扫频激励与双ADC采集链路，同步测量未知滤波电路的实际输入和输出，计算各频点的幅值比与相位差，获得幅频、相频特性并拟合二阶传递函数。复现阶段断开未知电路，采集外部信号发生器输入，软件根据已辨识模型实时计算系统响应并由DAC输出；

•完成不同类型滤波器识别，复现输出与实测响应相对误差不超过10%。

## 开源内容

- `F4_PM_work_最终/`：STM32F4固件工程
- `H7_2025_G_work_最终/`：STM32H7固件工程
- `已知模型.epro2`：已知模型电路嘉立创EDA工程
- `放大7倍.epro2`：运放7倍放大及信号调理电路
- `滤波器类型.epro2`：不同类型滤波器测试电路
- `README.md`：项目原理、硬件连接及使用说明

## 主要功能

- AD9959/DAC扫频信号输出
- ADC双通道输入与响应采集
- 1.65 V偏置及模拟信号调理
- 幅频、相频特性测量
- 二阶系统传递函数拟合
- 未知滤波器类型及参数识别
- 模型响应实时计算与DAC波形复现
